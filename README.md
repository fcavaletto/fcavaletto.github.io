# fcavaletto.github.io

The project switcher follows Federico’s [Completed](https://github.com/stars/fcavaletto/lists/completed) and [Research in progress](https://github.com/stars/fcavaletto/lists/research-in-progress) lists. After editing either list, run `python3 scripts/refresh-projects.py` and commit the refreshed `projects.json`. Visitors read that snapshot. New repositories appear by name and link, and their optional short introductions live in `app.js`.
